# Менеджер задач (Task Manager)

React-приложение для просмотра списка задач, загруженных из открытого API [JSONPlaceholder](https://jsonplaceholder.typicode.com).

## Функциональность

- **Список задач** — загрузка и отображение 10 задач с JSONPlaceholder
- **Индикация статуса** — каждая задача помечена как выполненная (`✔`) или невыполненная (`❌`)
- **Обработка состояний** — отображение загрузки и ошибок при запросе данных
- **Навигация** — две страницы: список задач и страница «О приложении» с помощью React Router

## Технологии

- **React 19** — библиотека для построения пользовательских интерфейсов
- **React Router 7** — маршрутизация между страницами
- **Vite 7** — сборщик и инструмент разработки
- **ESLint** — статический анализ кода

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Просмотр продакшен-сборки локально
npm run preview
```

## API

Приложение использует эндпоинт `https://jsonplaceholder.typicode.com/todos?_limit=10` для получения 10 задач. Данные загружаются асинхронно с обработкой состояний загрузки и ошибок.
